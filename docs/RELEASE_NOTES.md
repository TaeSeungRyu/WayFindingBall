# 릴리스 노트

Play Console 업로드 기준 버전별 변경 이력. 최신 버전이 맨 위.

각 항목은 **사용자 대상 문구**(Play Console "새로운 기능"에 그대로 붙여넣기용, 언어별 500자 제한)와 **기술 요약**으로 나눈다.

---

## 2.3.0 (versionCode 12)

**사용자 대상**
```
🎮 즐길 거리가 더 많아졌어요!
- 숫자·한글 배우기: 한글 자음(ㅊ~ㅎ)·모음·알파벳(A~I) 단계가 늘었어요.
- 색깔 찾기: 깜깜한데 술래가 오거나, 순서를 기억하는 더 짜릿한 단계 추가!
- 굴려서 맞히기: 지그재그 범퍼와 움직이는 표적 등 새 단계 추가!
```

**기술 요약**
- 새 게임 규칙·화면 없이 기존 데이터(`stages`)만 확장 — 선택 화면·기록·별점 합계는 리스트를 순회하므로 자동 반영.
- 배우기 6~8단계: 한글 ㅊ~ㅎ(자음 14개 완성)·한글 모음·알파벳 A~I (`game/LearnGame.kt`).
- 색깔 11~13단계: dark+chaser / memorizeOrder+dark / memorizeOrder+chaser+dynamicWalls (`game/ColorGame.kt`).
- 맞히기 11~13단계: 새 아레나(지그재그 범퍼) / ordered+dynamicWalls / ordered+moving+dynamicWalls (`game/HitGame.kt`).

## 2.2.0 (versionCode 11)

**사용자 대상**
```
🎓 새 게임 '숫자·한글 배우기' 추가!
- 바닥에 흩어진 숫자·글자를 순서대로(1→2→3, ㄱ→ㄴ→ㄷ) 공을 굴려 밟아요.
- 밟을 때마다 소리로 읽어줘서 숫자·한글·알파벳과 순서를 자연스럽게 배워요.
- 타일마다 색이 달라 알록달록! 숫자·한글·알파벳 5단계로 즐겨요.
```

**기술 요약**
- 새 모드 `game/LearnGame.kt` · `ui/LearnGameScreen.kt` · `ui/LearnStageSelectScreen.kt` · `data/LearnRecordsRepository.kt`. 홈 → 모드 선택 6번째 카드로 배선, 내 기록에 섹션 추가.
- 타일은 2x2 구역(색상별), 순서대로 밟으면 진행. 밟을 때 `SoundManager.speak`로 라벨을 읽어줌. 순서 아닌 타일은 무시(살짝 피드백). 완주 시간·별점 기록.
- 5단계: 숫자 1~5·1~9, 한글 ㄱ~ㅁ·ㄱ~ㅈ, 알파벳 A~E.
- 내부 개선: `PaintGameScreen` 리팩터(뷰·헬퍼·AI/벽 틱 분리, 1354→약 790줄), 색칠 기록 라벨을 시간/칸수로 구분 통일.

```

- 그림 따라 칠하기(꽃·집·나비)와 거울 대칭 그리기로 나만의 그림을 만들어요.

```

**기술 요약**
- 새 모드 `game/PaintGame.kt` · `ui/PaintGameScreen.kt` · `game/FloorPaintController.kt` · `data/PaintRecordsRepository.kt`. 홈 → 모드 선택에 5번째 카드로 배선.
- 1~7: 솔로 칠하기(광장→미로)·색 고르기. 8~13: AI 대결·팀전·땅따먹기(덮어쓰기)·동적 벽·술래·폭탄·별 구역 2배 점수. 14~16: 색칠 도안(꽃·집·나비). 17: 거울 대칭 그리기.

## 2.0.4 (versionCode 9)

**사용자 대상**
```
✨ 별자리 만들기 개선
- 만든 별자리를 플레이할 때 모양이 눌려 보이던 문제를 고쳤어요. 이제 만들 때와 똑같은 비율로 나와요.
- 별자리 저장 화면에서 그림(이모지)이 잘려 보이던 문제를 고쳤어요.
```

**기술 요약**
- 만들기 캔버스(`ui/ConstellationCreateScreen.kt`의 `StarCanvas`)를 정사각형화해 플레이 화면(`ConstellationCanvas`)과 종횡비 일치 → 모양 눌림 해결. 좌표는 정규(0..1)라 기존 저장 별자리도 마이그레이션 없이 정상 표시.
- 저장 다이얼로그 이모지 피커를 고정 크기에서 `weight(1f).aspectRatio(1f)`로 변경 → 우측 잘림 해결.
